📦 APK-файл APK загружается не здесь, а через GitHub Releases:
  1. Открой github.com/.../morozhka-files/releases
  2. Нажми Create a new release
  3. Загрузи APK как бинарный файл
  4. Скопируй ссылку на файл
  5. Вставь её в форму публикации или в админку
Почему так? GitHub Releases — бесплатно, 2 ГБ на файл, без ограничений. Supabase Storage — только 1 ГБ на всё.
